# [YX TIKTOK 公会主播建联工具](https://www.yxtiktok.com/tutorials/)｜TikTok公会招募新人主播和成熟主播，沟通策略有什么区别？

## 一句话核心差异

新人主播：卖「培训、保底、陪跑、降低试错成本」，角色是教练 + 保姆；成熟主播：卖「增量资源、效率提升、收益上限、自由度」，角色是商业合伙人、操盘顾问。成熟主播已经会直播、懂分成，最怕被管控、被放养；新人怕不会播、没收入、没人带、踩坑。

## 一、新人主播（素人 / 偶尔开播、没稳定流水）

### 核心痛点

不知道怎么起号、不会话术、不懂平台规则、担心播了没收入、怕没人带、怕被骗、不知道直播能不能当成副业 / 主业，对分成、合同理解很浅。

### 沟通策略

- 1. 破冰：低压力、先建立安全感，不要一上来谈签约

不要群发 “来我们公会吧”；先夸他的特质（长相、性格、才艺），告诉他零基础也可以、手机就能开播、不用前期投入。

示例：看你视频很有感染力，很多和你一样的素人从零开始做 TK 直播，我们有整套新手陪跑，如果你想试试副业，我可以简单跟你讲流程，不强求签约。

- 1. 价值重点：标准化扶持、兜底、教学，而不是高分成

重点讲：新人训练营、镜头 / 话术 / 选品 / 平台规则培训、开播脚本、场控陪播、冷启动流量扶持、试播指导、保底方案（如有）、固定运营对接、开播提醒、问题随时响应。

分成可以后面再说，新人优先关心：我能不能学会、会不会白忙活、有没有人管我。

- 2. 打消顾虑：简化合同、试错门槛、讲清楚退出机制

新人最担心被套牢、违约金。主动说明试播周期、无理由退出规则、不强制超长时长，弱化 “绑定” 感，强调先试播、看自己适不适合。

- 3. 节奏：慢、多陪伴、教育型沟通

多提问：你是想副业还是全职？每天能拿出多久？有没有才艺？能不能稳定上线？

沟通重心是帮他建立预期，告诉他新人前 1–2 周数据会怎样，不要画大流水大饼。

- 4. 避坑：不要吹高流水，新人很容易预期崩盘

## 二、成熟主播（稳定开播、有基础流水、有粉丝 / 老公会、懂直播逻辑）

### 核心痛点

上家公会放养、流量资源不给、PK 资源少、结算慢、分成不透明、运营不懂他赛道、约束太多、上限卡住；他要的不是 “教我怎么播”，而是怎么赚更多、少麻烦、拿到自己拿不到的资源。

### 沟通策略

- 1. 破冰：精准、专业，直接聊他的数据，不要鸡汤

先看他直播间、历史流水、粉丝、赛道、PK 情况，开口就要体现你懂行，不要泛泛夸奖。

示例：我看你最近稳定开播，互动很好，但段位一直卡在 XX，上家很少给你匹配高质量 PK、活动资源对吧？我们可以给你配套 XX。

- 1. 价值重点：增量资源、结算、赛道资源、自主权、收益优化

重点讲这几块：

- PK 匹配、主播圈子、连麦资源、官方活动报白、流量包 / PR 资源；
- 结算周期、对账透明、无克扣、阶梯分成方案；
- 专属运营做复盘、数据拆解、内容优化、变现方案（礼物 / 商单 / 广告）；
- 弹性开播要求、不强制固定脚本、不随意干涉直播风格（成熟主播非常反感被管镜头、话术）。

不要反复跟他说 “我们会教你直播”，这会让他觉得你不懂他。

- 1. 谈判重心：对比「增量收益」，而不是单纯比分成数字

成熟主播会同时对比多家公会。不要只说 “我们分成更高”；要算清楚：

同样的分成，我们能给到的资源，帮他每月多带来多少流水；

如果别家分成略高，但没有资源、放养，长期总收入反而更低。

同时问清楚：上家约束、合约到期时间、有没有违约金、当前瓶颈。

- 2. 节奏：高效、对等、合伙人式沟通

少说教，多听他吐槽上家的问题；带着案例、同赛道主播后台数据截图、资源案例说话；快速切入合作方案，不拉扯漫长的科普。

- 3. 避坑：不要贬低前公会；不要承诺无法落地的资源（比如无限流量）

## 三、对比表（方便经纪人直接用）

- 维度：沟通定位；新人主播：教练 + 陪跑者，降低门槛；成熟主播：商业顾问 + 资源合作方，放大收益
- 维度：开场切入点；新人主播：潜力、适合直播、零基础可做；成熟主播：直播间数据、当前瓶颈、资源缺口
- 维度：主推卖点；新人主播：培训、陪播、冷启动扶持、保底、试错保障；成熟主播：PK 资源、官方活动、结算、数据复盘、商单渠道、自由度
- 维度：优先顾虑；新人主播：怕学不会、没收入、被坑、被绑定；成熟主播：资源不足、被放养、分成不透明、管控太多、上限低
- 维度：合同沟通；新人主播：重点讲退出、试播、低风险；成熟主播：重点讲权责、资源清单、结算规则、违约边界
- 维度：沟通节奏；新人主播：慢、多次、教育引导、建立信任；成熟主播：快、精准、直击痛点、讲回报 ROI
- 维度：话术避雷；新人主播：别吹月入很高；成熟主播：别跟他说 “我们教你怎么直播”

## 四、通用但容易踩的红线（TK 海外公会尤其重要）

- 1. 海外主播对信任非常敏感，不要群发模板 DM，最好看完他直播再私信；
- 2. 不承诺私下换汇、线下转账、不合规结算；
- 3. 不要拿高额保底疯狂砸新人，后续兑现不了极易纠纷、差评；
- 4. 成熟主播很多有合约在身，先确认合约状态，避免纠纷。

Hi XX，刚刚看了你直播，你的性格很适合 TK 直播。很多零基础的主播在我们这边从 0 起步，我们有全套新人培训、运营陪跑，前期不用你自己摸索。如果你想了解副业增收，我可以简单跟你讲，没有强制签约。
