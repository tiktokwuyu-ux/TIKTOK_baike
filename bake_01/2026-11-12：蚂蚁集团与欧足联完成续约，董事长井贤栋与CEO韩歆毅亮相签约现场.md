# TikTok公会如何根据目标国家选择主播招募渠道？

## 核心逻辑

选渠道的底层判断标准：当地主流社交软件、信任习惯、人才供给、合规与文化、付费沟通工具；优先「站内挖掘 + 本地社群 + 本地代理」，再搭配校园 / 线下 / 广告投放；同时避开当地敏感、违规的挖人方式（不要硬挖别家签约主播）。

通用基础渠道（所有国家都能用，只是优先级不同）

- 1. TikTok 站内：直播广场、创作者市场、潜力新人账号（1k–2w 粉、稳定开播、无公会）私信建联
- 2. 老主播裂变内推：设置推荐奖励，转化率和留存普遍最高
- 3. 本地合作：本地小 MCN、才艺工作室、舞蹈 / 音乐院校、本地经纪人
- 4. 官方 Creator Network 渠道：TikTok LIVE 后台邀约入口

## 分区域渠道方案

### 1. 东南亚（泰国、越南、马来西亚、菲律宾、印尼）

特点：新人多、副业意愿强、沟通靠本地 IM，信任建立快，适合批量招素人

- 泰国：LINE \> TikTok 私信 \> WhatsApp；Facebook 群组、校园社团、音乐学院、本地才艺工作室；泰语招募帖优先发 LINE 社群
- 越南：Zalo为主，Facebook 小组；高校艺术系、本地 Bigo、Nonolive 老主播迁移
- 马来西亚：WhatsApp；FB、IG、本地华人社群、校园
- 菲律宾：Viber、WhatsApp；FB 大群、校园、小型本地经纪，菲律宾本土 MCN 资源非常多

适合：低成本批量起量，适合新手公会；缺点是主播竞争大、保底内卷严重

### 2. 中东 MENA（沙特、阿联酋、海湾六国）

特点：ARPU 高、宗教敏感、主播对收入机会敏感，非常依赖本地阿拉伯语经纪人，不能直接硬广乱私信

- 主渠道：WhatsApp、Telegram 本地创作者群；本地合作经纪 / Studio、阿拉伯语 KOL 圈子；官方 LIVE Creator Network 邀约通道
- 辅助：IG、Snapchat；线下艺术院校、音乐节；不要随便在公共群组发粗暴招募广告，容易被举报
- 沟通：优先阿拉伯语本地经纪人对接，不要中国经纪人直接大批量私信，信任门槛极高；内容、着装、话术必须合规宗教规则

### 3. 欧美（英国、德国、西班牙、法国、美国）

特点：主播警惕性高，反感 “直接谈钱”，重视长期成长、合同透明，私域 Discord 为主

- 主渠道：Discord 创作者社群、Instagram、TikTok 站内精准评论种草（先聊内容，再谈公会）；高校传媒 / 表演专业、独立音乐人、舞蹈工作室
- 辅助：LinkedIn、本地独立创作者论坛；少量 FB 小组；付费 Meta 广告（招素人）
- 重点：欧美主播很看重合同、税务、版权；不要群发垃圾私信，回复率极低；适合精细化孵化，不适合粗暴批量收割

### 4. 拉美（墨西哥、巴西、哥伦比亚）

特点：表演欲强、才艺资源丰富，喜欢社交、线下活动，FB/IG 普及度高

- 主渠道：IG、Facebook 本地创作者小组、TikTok 站内；线下音乐节、舞蹈教室、艺术学校、网红孵化工作室
- 辅助：WhatsApp 社群；主播内推奖励效果很好；拉美很多舞者、歌手愿意转直播主播36氪

### 5. 日韩

- 日本：LINE、Twitter (X)、Instagram；线下 Livehouse、演艺事务所、专科艺术学校；日本主播非常看重契约、口碑，慢转化，不适合粗暴私信
- 韩国：KakaoTalk、X、IG；小型演艺练习生工作室、舞蹈学院；行业内卷，头部经纪资源封闭，适合从小素人慢慢孵化

## 渠道优先级选择模型（你可以直接套用）

- 1. 先判断目标国首选通讯工具（决定你用什么工具加好友深度沟通）
- 2. 市场成熟度：

成熟市场（菲律宾、马来）：站内挖新人 + 本地代理，快速起量

高 ARPU 谨慎市场（中东、欧美）：本地合作经纪 + 社群种草，慢转化、重信任

蓝海市场（巴尔干、东欧）：高校合作 + Telegram 创作者群，竞争小

- 3. 人才类型：

才艺主播（唱歌、舞蹈）：艺术院校、线下演出机构、舞蹈室

聊天 / 日常素人：本地社交群组、站内低粉活跃新人

有经验主播：其他直播平台迁移（Bigo、YouNow 等），注意平台竞业风险

## 避坑要点

- 1. 不要跨区域用同一套话术：中东主打收益机会；欧美主打成长、扶持、社区；东南亚主打稳定保底、培训、结算清晰
- 2. 合规红线：禁止批量爬虫私信、挖已签约主播；很多国家要求本地税务、劳工合同，不能只用海外线上协议
- 3. 语言：招募帖、对接人尽量用本土语言，英文仅作为辅助，会大幅提升回复率
- 4. 结算信任：东南亚 / 拉美主播最关心准时发薪；欧美关心税务申报；中东关心合规结算方式

## 简单落地步骤

- 1. 锁定目标国家，确认当地主流 IM、主流社交平台
- 2. 准备本地化招募素材（本土语言海报、福利、合同摘要）
- 3. 渠道组合：站内精准挖掘 + 本地社群投放 + 1–2 家本地经纪合作
- 4. 上线内推奖励机制，放大存量主播裂变
- 5. 分渠道统计回复率、试播率、留存，慢慢砍掉低效渠道
