# [YX TIKTOK 主播查重工具](https://www.yxtiktok.com/tutorials/)｜TikTok公会如何制定主播招募计划？每天应该安排哪些工作？

核心思路：先定赛道 + 地区，锁定目标主播，多渠道建联、标准化试播、分阶段 KPI、合规签约；重点抓留存率，而不是只堆签约数量

## 1、前期定位（先写清楚）

1）目标市场：印尼 / 马来 / 菲律宾 / 拉美等，

按当地时区、语言、文化、平台规则分开做方案

（宗教、禁忌、合规红线一定要提前整理）

2）赛道选择：娱乐聊天、才艺、PK、脱口秀、游戏、本地生活，不要同时铺太多赛道

3）主播类型区分

- 线上居家主播（最多，招募主力）：自备手机、网络、安静背景，弹性时段
- 线下基地主播：到棚开播，公会提供设备、灯光、化妆、运营陪播

4）招募指标（建议分阶段）

- 冷启动期（1 个月）：经纪人每人每日有效建联 15–25 人，试播 3–5 人，目标签约 2–4 人；重点看试播留存
- 稳定期（2–3 个月）：提升转正率、开播率、流水，降低流失；老主播裂变奖励上线
- 成熟期：控制新人引入速度，重点深耕成熟主播、头部主播孵化

## 2、主播准入标准（筛选标准）

✅ 硬性：年满 18 周岁、无平台封禁记录、

未绑定其他公会

（严禁挖别家签约主播，会违规扣分）、网络稳定、镜头干净、环境合规

✅ 软性：面对镜头不怯场、愿意按时开播、听得懂运营指导；优先选：稳定开播的小素人（1k–5k 粉、每周开播≥2 次、直播间互动不错），不要优先大主播，转化极低

✅ 淘汰项：擦边倾向、语言暴力、不配合培训、经常跳票、频繁断播

## 3、招募渠道（4 大渠道组合）

1）TikTok 站内挖掘（主力渠道）

刷直播广场、同赛道直播间，标记无公会主播；看主页回放、评论互动、直播时长；经纪人号养垂直标签，精准刷同类直播间；私信话术不要群发大饼，结合对方直播内容去聊

2）站外社媒渠道

IG、Facebook 本地小组、本地校园社群、本地短视频社群，发本地化招募海报；本地兼职平台投放

3）老主播裂变（性价比最高）

伯乐奖励：推荐主播成功签约 + 完成试播期、达标开播时长，给一次性现金奖励 / 流量包；师徒制，成熟主播带新人，拿新人阶段性激励，留存更高

4）合作渠道：本地经纪、院校才艺社团、独立小工作室置换合作

## 4、完整招募 SOP 流程

- 1. 线索收集标记：记录主页链接、直播风格、开播时区、粉丝、是否有公会、基础数据，录入线索表
- 2. DM 建联初沟通：介绍公会福利、分成、扶持、运营服务、平台规则，同步主播疑问（保底、结算、退会、任务）
- 3. 初步面试（语音 / 视频）：确认时区、语言、可直播时长、设备、对直播的理解，同步公会任务规则
- 4. 试播考核（3 天试播期，非常关键）：运营陪看，看镜头感、互动、稳定性、违规风险；试播标准：按时上线、基础互动、不违规
- 5. 政策确认、合同讲解：分成、任务时长、结算周期、保底条件、退会规则、违约责任，全部本地化语言，清晰透明，禁止隐藏高额违约金陷阱新华网
- 6. 后台邀约绑定签约、进主播群、分配专属运营
- 7. 新人上岗培训、开播排期、冷启动扶持

## 5、主播激励 & 扶持方案（写进招募方案）

- 收益：平台分成 + 公会补贴（保底一般绑定时长 / 有效开播任务，不建议无条件无责保底）、阶梯提成、流水奖金、活动奖励
- 扶持：一对一运营、直播话术包、PK 匹配、活动资源、短视频引流、违规申诉协助、直播间问题实时支持
- 任务标准举例（按站点调整）：月有效开播≥60–80 小时、单场≥2 小时，不跨时区乱播；每周固定休息

## 6、风控 & 合规条款（TikTok 公会生命线）

- 禁止诱导消费、擦边、违规 PK、虚假承诺保底、数据刷量、诱导未成年人
- 所有签约走官方公会后台邀约，私下协议风险极大；留存沟通记录、身份核验记录
- 提前同步当地文化禁忌、平台 CHR 健康分规则，健康分过低会限流、限制公会权限

## 二、经纪人 / 招募运营【每日固定工作 SOP】

按目标地区时区排班（东南亚时区和国内时差小；欧美夜班为主），核心指标：有效建联数、试播数、签约数、线索跟进转化率

### 早上（复盘 + 准备）

- 1. 看昨日数据看板：经纪人线索量、回复率、试播、签约、流失；主播侧：开播率、断播、违规、流水、投诉
- 2. 昨日未跟进线索复盘：标记意向强 / 犹豫 / 拒绝的主播，准备二次跟进话术，拒绝的打标签沉淀原因
- 3. 接收平台通知：新规、活动、健康分、处罚提醒，更新话术和招募政策
- 4. 物料检查：本地化招募海报、DM 话术版本、报名表、试播告知文档、合同模板

### 核心时段：挖掘 + 建联（对应目标地区直播黄金档）

- 1. 直播间扫素人：刷直播广场，筛选无公会潜力主播，建立线索库，标注标签（风格、时区、互动好坏）
- 2. 私信建联：不要一次性大量群发，容易风控；每条尽量带上对方直播间细节，提高回复率；

每日建议：15–25 个高质量建联，而不是 100 条垃圾私信（大量群发容易封号、降权）

- 3. 及时回复主播咨询：主播回复后 15–30 分钟内响应，解答分成、保底、任务、退会疑问，打消顾虑
- 4. 邀约面试：意向达标主播安排语音面试，同步试播安排

### 下午 / 晚班：试播跟进 + 签约 + 新人交接

- 1. 陪看试播：记录试播主播问题（镜头、话术、违规点、节奏），输出试播评估表，决定是否转正签约
- 2. 意向主播逼单、政策再次确认，发起公会后台邀约；核对身份信息、年龄核验
- 3. 签约成功主播：拉群、分配运营、下发新人培训包、排开播时间表
- 4. 老主播裂变维护：提醒伯乐奖励，鼓励老主播推荐新人

### 收尾工作（下班前 30–60 分钟）

- 1. 线索表更新：状态更新（待回复 / 意向 / 试播 / 签约 / 拒绝），打标签
- 2. 今日日报：建联数量、回复数、面试、试播、签约、拒绝原因、遇到的问题
- 3. 话术迭代：记录主播高频疑问，优化 DM 话术、FAQ
- 4. 黑名单维护：标记恶意主播、别家公会签约主播、高风险擦边主播，避免重复触碰违规

## 三、公会主播运营侧每日工作（招进来之后的留存工作，招募计划必须配套）

招募只是第一步，留存决定公会盈利：

- 1. 开播盯档：按时区盯主播上线，提醒开播、卡点、补时长，处理临时请假、断播
- 2. 直播间实时支持：帮主播控评、提醒违规、协助 PK 匹配、引导互动
- 3. 主播沟通：情绪安抚、数据反馈，告诉主播本场哪里好、哪里要调整
- 4. 培训：新人基础课（平台规则、礼物话术、留人、避坑）、成熟主播进阶（PK 玩法、短视频引流）
- 5. 数据核对：每日看主播在线时长、观看、互动、钻石流水，标记低产出、低开播主播做沟通抢救
- 6. 违规申诉、问题上报：直播间被掐流、封号、误判，走公会官方渠道申诉
- 7. 结算核对：记录任务达标情况，为月度结算做准备，保证准时发放，避免信任崩塌

## 四、配套表格（直接落地）

- 1. 主播线索表：ID、主页链接、时区、风格、联系时间、沟通记录、状态
- 2. 试播评估表：镜头感、互动、合规、稳定性、是否录用、改进点
- 3. 经纪人每日 KPI 表：建联、回复、面试、试播、签约
- 4. 主播台账：签约日期、任务、开播记录、流水、奖励、到期时间

## 五、常见避坑提醒

- 1. 不要疯狂堆私信数量，风控封号是高频问题，重质量、个性化话术
- 2. 不要过度承诺：无限保底、零任务、随时退会，后期无法兑现会大量流失 + 投诉
- 3. 时区错配是新人公会最大坑：主播黄金直播时间≠国内白天，排班必须跟着目标国家时间走
- 4. 招募和运营要配比：招得多、没人带，主播 7 天流失率极高，白白浪费招募人力
