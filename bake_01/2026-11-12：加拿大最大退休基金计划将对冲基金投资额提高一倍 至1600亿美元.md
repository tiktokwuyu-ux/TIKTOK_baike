# TikTok新人主播培训有哪些内容？公会应该先教什么？

## 先说核心结论：公会新人培训，优先顺序：合规风控 \> 开播硬件 + 后台操作 \> 基础留人互动话术 \> 薪资与公会规则 \> 简单复盘，PK、打礼物套路、带货逼单、短视频引流全部往后放，新人第一阶段不要学，容易违规、心态崩、封号。

很多公会踩坑：上来就教 PK、要礼物、逼单，新人违规封号、不会接零观众的冷场、流失率极高。

## 一、公会最先教（0 基础首播前必学，1 天搞定）

### 1. 平台合规红线（最重要，保命课）

- 当地区域 TikTok LIVE 规则、禁词、违规行为：宗教、政治、种族歧视、色情暗示、极限词、版权 BGM、不能引导站外、不能诱导刷礼物、不能虚假宣传（带货）
- 处罚后果：限流、断播、封号、扣公会分成、取消公会权限；给新人看本地真实违规案例
- 直播间应急：黑粉、恶意提问、敏感话题怎么温和回避，不要对线
- 区分：不同国家 / 地区规则不一样，东南亚、欧美、中东禁忌差异很大

### 2. 账号、设备、网络、开播全流程（实操，手把手）

- 账号状态检查：直播权限、礼物钻石权限、年龄、粉丝门槛、账号是否干净
- 设备：灯光、支架、收音、网络（专线 / IP，延迟、卡顿怎么排查）、背景、镜头构图
- 开播后台：封面、标题、分类、公告、置顶评论、礼物面板、钻石收益入口、下播按钮；带货主播额外学商品卡、优惠券、闪购设置
- 标准开播→下播流程，练一遍模拟开播，确保自己能独立开播、下播，不会误操作关播、漏开功能

### 3. 基础心态 + 最低版互动话术（解决冷场、不敢说话）

新人最大问题：没人就沉默、紧张、不知道说什么

- 核心认知：前几场 0 - 几个人是常态，不是你不行；稳定时长、稳定开播优先级＞高在线
- 固定万能话术模板（本地化英文 / 当地语言）：

进人欢迎、点名感谢、感谢礼物、引导 follow、简单提问留人

冷场兜底话题库（日常话题，不用才艺）

一句话人设：你是谁、直播间是干嘛的

- 训练：模拟零观众状态下持续说话，不要停、不要发呆盯屏幕

### 4. 公会契约、薪资结算、时长考核（讲清楚，降低预期）

- 公会分成、钻石换算、结算周期、扣罚规则、保底条件、停播 / 请假规则
- 开播时长、排期、迟到早退、断播处罚；公会给什么支持（运营、中控、素材）
- 预期管理：前 1-2 周很难有高流水，不要画大饼，减少新人落差流失

### 5. 基础数据认知（只讲 3 个）

只教最简单：平均停留、进房率、粉丝 / 礼物转化，知道开播看什么，不用复杂 GPM、PV；学会看回放，知道自己哪里冷场了。

✅ 第一阶段目标：新人能安全、独立、稳定开播，不违规、不慌、知道怎么和进来的人说话，完成基础时长。

## 二、完整 TikTok 新人主播培训全部内容（分阶段）

### 阶段 1：开播筑基（首播前，上面优先内容）

合规风控｜设备网络｜后台操作｜薪资考核｜基础留人话术｜心态训练｜模拟试播

### 阶段 2：留存和流量（开播 3-7 天，稳定开播后）

- 直播间钩子：前 30 秒留人话术，标题封面怎么写，提升点击进房
- 评论区维护：怎么引导打字、提问，接住观众的话，维护老粉
- 粉丝维护：识别常驻观众、简单维护，建立私域 / 粉丝群（平台允许范围内）
- 算法基础：什么行为会推流（停留、互动、关注、礼物），什么行为会掉流量（长时间静止、黑屏、沉默）

### 阶段 3：变现技能（分赛道：娱乐打赏主播 / 带货主播二选一）

### 娱乐打赏主播

- 礼物识别、感谢节奏、自然引导礼物（严禁硬要、道德绑架）
- PK/Battle 基础规则、匹配、输赢心态、PK 话术（这里晚一点再教，新人容易上头违规）
- 连麦、多人局、直播间氛围调动、才艺植入（唱歌、舞蹈、聊天梗）

### TikTok Shop 带货主播

- 产品熟悉：FABE 卖点、常见 FAQ、差评问题应对
- 直播节奏：引流款、利润款讲解顺序、上车、弹窗、优惠券配合
- 转化话术、信任塑造、本地化表达，本地用户消费习惯、节日热点
- 中控配合：什么时候弹链接、置顶、改价、发福利

### 阶段 4：进阶增长（稳定出数据之后）

- 短视频引流：直播切片、预告短视频，给直播间引流
- 直播复盘：每场回放拆解，停留低点、掉人节点、转化问题
- 活动：平台 LIVE 活动、公会活动怎么报名、玩法
- 人设优化：找到适合自己的风格，持续优化

### 阶段 5：高阶（成熟主播）

付费投放 Promote、直播矩阵、团播、排期规划、主播个人 IP、粉丝精细化运营

## 三、避坑提醒（公会培训常见错误）

- 1. 不要一上来堆大量话术、长脚本，新人记不住，只会更紧张
- 2. 不要刚开播就强制 PK、冲流水，新人容易被打击 + 违规
- 3. 合规不能只是发文档，要案例 + 抽查，东南亚、中东对敏感内容管控极严
- 4. 语言优先本地化，不要直接用中式英文，观众听不懂，留不住人

## 四、简易新人培训 SOP（公会直接用）

Day1：合规 + 账号设备 + 后台操作 + 薪资规则 + 模拟试播

Day2：基础话术、冷场训练、试播 30 分钟，运营实时陪听纠错

Day3：正式开播，运营在线盯场，下播简短复盘，只改 1-2 个问题，不一次性提一堆缺点

Day7：达标后，再开启 PK / 带货专项培训
