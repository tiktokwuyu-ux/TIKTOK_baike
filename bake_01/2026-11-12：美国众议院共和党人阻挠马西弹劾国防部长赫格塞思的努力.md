# [YX TIKTOK 海外主播建联软件](https://www.yxtiktok.com/tutorials/)｜TikTok公会如何通过短视频寻找有直播潜力的创作者？

核心原则：粉丝量不重要，优先找镜头表现力、互动感、稳定更新、还没签约公会、直播意愿高的素人 / 小创作者；很多几千粉甚至几百粉的短视频博主，比大博主更容易孵化成稳定主播。

## 一、短视频线索从哪里找（获源渠道）

- 1. 标签 & 话题池挖掘（免费主力）

按站点和赛道搜标签：\#tiktoklive \#smallstreamer \#livestreamer，以及垂直标签：美妆、dance、comedy、gaming、food、fashion；

优先刷「近期热门 BGM、本地热门音效」下面的投稿，这类创作者本身对流量敏感，愿意做内容，转化直播概率更高。

经纪人账号先养本地标签，长期刷同赛道，推荐流会持续推同类新人，不用盲目大海捞针。

- 1. 官方后台工具
- Creator Marketplace / Find Creators：公会后台达人广场，可以筛地区、类目、是否归属其他机构、视频互动数据、有没有直播历史；直接过滤已经签公会的账号，规避违规挖角。
- TikTok One 达人搜索：按地区、受众年龄性别、视频中位数播放、互动率筛选。
- 1. 竞品 / 同赛道直播间的短视频关联

看同类主播评论区、主页推荐、合拍、duet（对拍）的账号；很多喜欢连麦、合拍的素人天生适合直播互动。

- 2. 公会自己发招募短视频反向引流

公会账号拍新人试播、主播收入案例、培训扶持内容，带上本地招募标签，吸引创作者主动私信报名，线索质量最高、信任成本最低。

## 二、短视频上，判断直播潜力的核心筛选标准（重点）

先看人，再看数据：短视频能看到的，是直播最重要的底层能力。

### ✅ 1. 镜头表现力（直播第一优先级）

点开多条视频观察：

- 面对镜头是否自然、敢直视镜头、表情丰富、说话流畅不僵硬；
- 表达节奏：能不能持续输出、有情绪起伏，不是只会摆姿势、对口型；
- 才艺 / 人设清晰：唱歌、跳舞、搞笑、穿搭、唠嗑、测评，有稳定人设的，直播更容易留住人。

纯静态拍照、全程不说话、眼神躲闪、表情麻木的直接 pass。

### ✅ 2. 评论互动能力（决定直播间留存）

看评论区：

- 创作者会不会主动回评、跟网友玩梗、接观众提问；
- 评论是不是在跟他 “对话”，而不是单纯点赞 “好看”；
- 评论区本地粉丝占比高（和公会目标站点一致）。

短视频愿意互动的人，直播里接弹幕、控场能力通常更好。

### ✅ 3. 数据指标（不要只看播放，看质量）

优先看近 10–30 条短视频：

- 完播率＞互动率（点赞 + 评论 + 分享 / 播放），高评论率＞高点赞；高评论代表用户想跟他交流，是直播潜力金标准；
- 稳定更新：每周至少 2–3 条，不是三天打鱼两个月不发；代表执行力、能坚持开播；
- 粉丝画像匹配：粉丝地区、年龄、性别，和公会主打赛道（娱乐秀场 / 带货 / 游戏）匹配；
- 粉丝增速：缓慢稳定上涨＞一条爆百万播放之后断更的 “一次性爆款号”。

避坑：百万播放但评论寥寥、全是过路流量的账号，直播大概率留不住人；很多几百粉、评论热热闹闹的素人反而更容易起来。

### ✅ 4. 账号背景排查（风控）

- 主页有没有标注 MCN/Agency、Live Agency，有没有固定公会；已经签约公会的不要联系，属于违规挖人，公会会扣分；
- 是否开过直播：少量开播、直播回放短视频、但没人带、不懂运营的，是黄金目标；完全没开过直播、愿意尝试的素人其次；
- 合规：内容无违规、无敏感、无侵权，语言是目标站点本地语言。

## 三、分级筛选流程（SOP，公会经纪人可以直接落地）

- 1. 粗筛（流览页）：标签 / 推荐流捞账号，排除已签约、长期断更、镜头僵硬；导出线索表
- 2. 细筛（主页逐条看视频 + 评论）：打分：镜头表达、评论互动、更新稳定性、受众匹配；分 A/B/C 类

A 类（优先建联）：表达自然、评论活跃、稳定更新、无公会、偶尔自己瞎开播

B 类（慢慢养）：表现力不错，但没直播想法，先关注、互动，慢慢种草直播收益

C 类：只适合短视频，不适合直播，放弃

- 3. 建联前置铺垫：不要一上来私信 “来签我们公会”；先正常点赞、评论他的视频，混脸熟；
- 4. 私信话术（本地化，简洁，讲痛点 + 价值）

模板思路（翻译成当地语言）：

“Hi，看了你几条视频，你镜头感很好，评论大家都很喜欢你。很多像你这样的创作者尝试 TikTok Live，我们公会提供免费直播培训、运营陪播、流量建议、稳定结算，没有强制任务。如果你想试试直播，可以聊聊，不强制签约。”

重点：不说虚高分成，突出培训、陪播、运营指导、帮解决直播没人、不会控场的痛点，海外创作者很吃这个。

- 1. 试播考核（最终验证，短视频筛选只是预判）

邀约后安排15–30 分钟无压力模拟试播，看：

- 没人进直播间的时候，能不能自说自话、不冷场；
- 看到弹幕会不会主动接话；
- 情绪能不能稳住、不怯场；

试播表现，才是决定要不要签约的最终依据。短视频只是帮你高效把候选人捞出来。

## 四、常见误区

- 1. 只找大粉达人：大达人要么已经签公会，要么议价极高，且很多短视频达人不适应直播长时间持续输出，翻车率很高；
- 2. 只看播放量：爆款偶然流量≠直播粘性；评论互动权重更高；
- 3. 批量群发私信：海外创作者反感垃圾 DM，回复率极低，还容易被举报；
- 4. 忽略本地语言和时区：招到一个表现力好，但和你站点时区、语言不匹配的，很难运营；
- 5. 把对口型、纯颜值摆拍号当成潜力主播：这类短视频靠颜值，直播容易冷场，没有持续输出能力。

## 五、团队效率提升方案

- 给经纪人固定赛道标签，每人专注一类（美妆 / 娱乐 / 游戏），更容易看懂赛道的评论氛围；
- 建立线索表格：账号 ID、地区、标签、得分、是否建联、回复状态、试播结果；
- 用第三方线索工具辅助采集（合规前提下），但所有账号必须人工复核视频和评论，机器只能做初筛；
- 老主播转介绍激励：主播推荐同圈层短视频创作者，签约并稳定开播后给奖励，这类新人匹配度最高。
